# DSA Mastery Path - Python

## Learning Path (Beginner → Master)

### Level 1: Fundamentals
1. **01_arrays.py** - Array operations
2. **02_strings.py** - String manipulation
3. **03_linked_lists.py** - Linked lists
4. **04_stacks.py** - Stack operations
5. **05_queues.py** - Queue operations

### Level 2: Intermediate
6. **06_hashing.py** - Hash tables
7. **07_recursion.py** - Recursion patterns
8. **08_sorting.py** - Sorting algorithms
9. **09_searching.py** - Binary search
10. **10_trees.py** - Binary trees, BST

### Level 3: Advanced Trees & Graphs
11. **11_advanced_trees.py** - AVL, Segment trees
12. **12_heaps.py** - Min/Max heap
13. **13_graphs.py** - Graph traversals
14. **14_graph_algorithms.py** - Dijkstra, Bellman-Ford

### Level 4: Advanced Techniques
15. **15_dynamic_programming.py** - DP patterns
16. **16_greedy.py** - Greedy algorithms
17. **17_backtracking.py** - Backtracking
18. **18_divide_conquer.py** - Divide and conquer

### Level 5: Master Level
19. **19_tries.py** - Trie data structure
20. **20_advanced_dp.py** - Advanced DP
21. **21_bit_manipulation.py** - Bit tricks
22. **22_math_algorithms.py** - Number theory
23. **23_string_algorithms.py** - KMP, Rabin-Karp
24. **24_advanced_graphs.py** - Tarjan's, Kosaraju's

## How to Use
Start from file 01 and progress sequentially. Run: `python 01_arrays.py`
